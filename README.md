# Дашборд программы улучшений

Публичный просмотр: https://barsuk-box.github.io/ecobox-improvement/

Просмотр задач, статусов и прогресса по этапам. Редактирование доступно только приглашённым пользователям после входа по кнопке на сайте. Прогресс — доля завершённых этапов; новые этапы являются предложенным планом и требуют подтверждения исполнителем.

## Устройство и запуск

Каталог `site` — готовый статический интерфейс. Для локального просмотра запустите любой HTTP-сервер из этого каталога, например `python -m http.server 8080`, и откройте localhost:8080. Зависимости для сборки не нужны.

GitHub Actions публикует `site` на Pages после push в main. Актуальные данные загружаются из существующей серверной базы Sites; снимки данных и учётные данные не включены в Git. Доступность просмотра зависит от API сервера. GitHub Pages не выполняет вход и запись в базу; кнопка входа открывает рабочую версию на сервере.

## Работа с этапами

Откройте карточку задачи. После входа редактор может уточнить этапы, отметить выполненные и сохранить изменения. Для закрытия всей задачи требуется завершить все этапы и указать результат приёмки. Публичный просмотр обновляет данные автоматически; при открытой карточке закройте её для обновления.
